# Stockfish notice

The Chess mode uses Stockfish 19 Android binaries when the APK is built by the
GitHub Actions workflow. The workflow downloads the official release archives
from:

https://github.com/official-stockfish/Stockfish/releases/tag/sf_19

The binaries and their source are distributed under the GNU General Public
License, version 3. The APK includes the Stockfish `Copying.txt` license file
in `assets/stockfish/Copying.txt`. Stockfish source and corresponding build
materials are available from the official repository:

https://github.com/official-stockfish/Stockfish
